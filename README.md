# Рагнар: Дороги Півночі

3D-гра в браузері про вікінга Рагнара: села зі старостами, завдання, три боси (Іней, Сурт, Фенрір), паркур на вулкані, чекпоінти, збереження, меню та 6 мов (uk, en, pl, de, es, ru).

## Запуск

Потрібен браузер із WebGL та інтернет (Three.js підвантажується з cdnjs).

```
python3 -m http.server 8000
```

Потім відкрийте http://localhost:8000. Можна й просто відкрити `index.html`.

## Структура

- `index.html` — розмітка та підключення Three.js r128
- `style.css` — інтерфейс і меню
- `game.js` — вся логіка гри: світ, шейдери, боси, квести, камера, переклади, збереження

## Керування

Джойстик ліворуч, ⚔ удар, ⤴ перекат, ⬆ стрибок. На комп'ютері: WASD, J, K, пробіл, Q/E і C (камера), Esc (пауза).
